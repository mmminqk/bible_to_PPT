# 📖 말씀 & 예배 PPT 변환기 (Bible to PPT)

성경 구절 주소를 입력하면 PowerPoint(PPTX) 슬라이드를 자동으로 생성해 주는 데스크톱 프로그램입니다.  
설교, 예배, 성경공부, 큐티(QT) 등에 필요한 성경 구절 및 교독문 슬라이드를 단 몇 초 만에 완성할 수 있습니다.

> 💡 **컴퓨터나 개발을 잘 모르시나요?**  
> 걱정하지 마세요! 아래의 **[🚀 초간단 설치 및 실행 가이드](#-초간단-설치-및-실행-가이드-누구나-따라-할-수-있어요)**를 순서대로 따라 하시면 누구나 5분 안에 프로그램을 설치하고 사용할 수 있습니다.

---

## ✨ 이런 기능들이 있어요!

- **한/영 성경 동시 지원**: 개역개정(한글) 및 ESV(영어) 성경 데이터 내장
- **언어 출력 선택**:
  - `한국어 + 영어`: 상단에 한글 구절, 하단에 영어 구절 동시 출력
  - `한국어만`: 한글 성경 구절만 깔끔하게 출력
  - `영어만`: 메인 화면에 영어(ESV) 성경 구절 출력
- **단어 강조 기능**: 강조하고 싶은 단어에 `'단어' 굵게` 또는 `'단어' 밑줄` 자동 적용
- **교독문 모드**: 인도자와 회중이 번갈아 읽는 교독문을 인도 1절 + 회중 1절씩 슬라이드로 자동 페어링
- **인용구 모드**: 설교 예화나 명언을 슬라이드 제목과 본문으로 자동 분할 생성
- **슬라이드 자동 분할**: 긴 구절은 가독성을 위해 적절한 분량으로 자동 분할
- **🕊️ 예배 전체 템플릿 통합 (NEW)**:
  - 주일 예배 및 수요 예배 템플릿에 찬양 PPT와 성경 본문을 순서대로 자동 결합
  - 원본 템플릿의 디자인(배경 이미지, 고정 문구 등)은 100% 유지하면서 필요한 곳에만 쏙 삽입!
- **원클릭 즉시 실행**: 단축키 `Ctrl + Enter` (Mac은 `Cmd + Enter`) 지원

### [1단계] 필수 프로그램 설치하기 (최초 1회만)

이 프로그램이 컴퓨터에서 작동하려면 **파이썬(Python)**과 **노드(Node.js)**라는 두 가지 무료 도구가 필요합니다.

#### 1. Python (파이썬) 설치
1. [파이썬 공식 다운로드 페이지](https://www.python.org/downloads/)에 접속합니다.
2. 노란색 **`Download Python 3.x.x`** 버튼을 클릭하여 설치 파일을 다운로드합니다.
3. 다운로드한 설치 파일(`python-3.x.x-amd64.exe`)을 실행합니다.
4. ⚠️ **[가장 중요!]** 설치 창 맨 아래에 있는 **`Add python.exe to PATH`** (또는 `Add Python to PATH`) 체크박스를 **반드시 체크**하세요!  
   *(이 체크를 빼먹으면 나중에 프로그램을 실행할 수 없습니다.)*
5. 맨 위의 **`Install Now`**를 클릭하여 설치를 완료합니다.

#### 2. Node.js 설치
1. [Node.js 공식 다운로드 페이지](https://nodejs.org/ko)에 접속합니다.
2. 초록색 **`LTS (안정적, 대부분의 사용자에게 권장)`** 버튼을 클릭하여 설치 파일을 다운로드합니다.
3. 다운로드한 파일을 실행한 후, 변경할 것 없이 **`Next`** 버튼을 계속 누르고 **`Install`**을 클릭하여 설치를 완료합니다.

#### 3. (선택/권장) 예쁜 글꼴(나눔스퀘어 네오) 설치
프로그램의 기본 글꼴은 네이버의 무료 글꼴인 **'나눔스퀘어 네오'**로 맞춰져 있습니다.  
컴퓨터에 이 글꼴이 없으면 다른 기본 글꼴로 대체되므로, 더 깔끔한 디자인을 원하시면 설치를 권장합니다.
- [네이버 나눔스퀘어 네오 무료 다운로드](https://hangeul.naver.com/font/nanum) (OTF 또는 TTF를 내려받아 압축 해제 후 더블 클릭하여 `설치`)

가장 편리한 **[방법 A: 마우스 클릭]** 또는 **[방법 B: 명령 프롬프트]** 중 편한 방법을 선택하세요.

#### 🟢 [방법 A: 추천] 더블 클릭으로 1초 만에 설치 & 실행하기

프로젝트 압축을 푼 폴더 안에 있는 편리한 배치 파일(`.bat`)을 이용하는 방법입니다.

   - 검은 창이 뜨며 필요한 도구들이 자동으로 다운로드 및 설치됩니다 (1~2분 소요).
   - "축하합니다! 모든 설치가 성공적으로 완료되었습니다!"라는 문구가 뜨면 아무 키나 눌러 창을 닫습니다.
2. **프로그램 켜기**:
   - 이제 **`실행하기.bat`** 파일을 **더블 클릭**하면 끝!
   - '말씀 & 예배 PPT 변환기' 창이 화면에 나타납니다.
   - *(바탕화면에 `실행하기.bat`의 바로가기를 만들어두면 언제든 편하게 켤 수 있습니다!)*

#### 💻 [방법 B] 명령 프롬프트(CMD)로 직접 설치 & 실행하기

명령어를 직접 입력하여 켜고 싶으신 경우 아래 순서대로 진행합니다.

1. 압축을 푼 폴더 내의 **`electron_app_py`** 폴더 안으로 들어갑니다.
2. **[꿀팁]** 폴더 창 위쪽의 **주소창**(경로가 적힌 네모 칸)을 마우스로 클릭하고, 영어로 `cmd`를 입력한 뒤 `Enter` 키를 칩니다.
3. 해당 위치에서 검은 창(명령 프롬프트)이 바로 열립니다.
4. 아래 명령어를 **한 줄씩 입력하고 Enter**를 누릅니다:

```bash
# 1) 파이썬 PPT 라이브러리 설치 (최초 1회만 필요)
pip install python-pptx

# 2) 프로그램 구동 모듈 설치 (최초 1회만 필요, 1~2분 소요)

# 3) 프로그램 실행하기!
npm start
```

잠시 후 예쁜 프로그램 화면이 실행됩니다!

## 🖥️ 프로그램 사용 방법

프로그램 화면은 크게 **[구절 입력]**, **[예배 통합]**, **[서식 설정]** 3개 탭으로 구성되어 있습니다.

```
┌────────────────────────────────────────────────────────┐
│  말씀 & 예배 PPT 변환기               [Ctrl + Enter로 변환] │
├───────────────────────────────┬────────────────────────┤
│ [구절 입력] [예배 통합] [서식 설정] │   슬라이드 미리보기    │
│                               │ ┌────────────────────┐ │
│ 1. 구절/교독문/인용구 입력 창     │ │                    │ │
│ 2. 언어 선택 (한국어/영어)       │ │  실시간 화면 반영  │ │
│                               │ │                    │ │
│                               │ └────────────────────┘ │
├───────────────────────────────┴────────────────────────┤
│   [ ▶ PPT로 변환 ]       [ 💾 다른 이름으로 저장 ]     │
└────────────────────────────────────────────────────────┘
```

### 1. 기본 구절 PPT 만들기 (가장 기본!)
1. 상단의 **[구절 입력]** 탭을 클릭합니다.
2. 텍스트 입력창에 원하는 구절을 입력합니다:
   ```text
   1. 창 1:1-3
   2. 요 3:16
   3. 롬 8:28
   ```
   - 반드시 **`번호. 성경약어 장:절`** 형식으로 작성합니다.
   - `시 23` 처럼 장만 입력하면 해당 장 전체를 가져옵니다.
3. 아래의 **언어 선택** 버튼을 클릭하여 원하는 모드를 선택합니다:
   - `한국어 (개역개정)`만 켜기: 한글 성경만 슬라이드에 표시
   - `한국어` + `영어 (ESV)` 둘 다 켜기: 위에는 한글, 아래에는 영어가 함께 표시
   - `영어 (ESV)`만 켜기: 영어 성경만 표시
4. 오른쪽 **슬라이드 미리보기**에서 글자가 예쁘게 나오는지 확인합니다.
5. 화면 아래의 **[PPT로 변환]** 버튼을 누르거나 키보드에서 `Ctrl + Enter`를 누릅니다.
6. 변환이 완료되면 자동으로 파워포인트(PowerPoint)가 실행되며 완성된 PPT가 열립니다!

---

### 2. 한 슬라이드에 여러 구절 넣기 (세미콜론 `;` 사용)
여러 구절을 한 화면에 모아서 보여주고 싶을 때는 세미콜론(`;`)으로 연결합니다.
```text
1. 창 1:1; 1:3; 롬 8:28
```

---

### 3. 특정 단어 강조하기 (굵게 / 밑줄)
원하는 단어 앞뒤에 작은따옴표 `'`를 감싸고 뒤에 `굵게` 또는 `밑줄`을 적어주면 해당 단어에 서식이 자동 적용됩니다.
```text
1. 고전 13:4-7 '사랑은' 굵게 '온유하며' 밑줄
2. 창 1:1 '태초에' 굵게 '하나님이' 굵게
```

---

### 4. 교독문(Responsive Reading) 슬라이드 만들기
예배 시간에 사회자와 회중이 번갈아 읽는 교독문도 손쉽게 만들 수 있습니다.
```text
1. <교독문> 시편 23편
[인도] 여호와는 나의 목자시니 내게 부족함이 없으리로다
[회중] 그가 나를 푸른 풀밭에 누이시며 쉴 만한 물 가로 인도하시는도다
[인도] 내 영혼을 소생시키시고 자기 이름을 위하여 의의 길로 인도하시는도다
[회중] 내가 사망의 음침한 골짜기로 다닐지라도 해를 두려워하지 않을 것은
[다함께] 내 평생에 선하심과 인자하심이 반드시 나를 따르리니 내가 여호와의 집에 영원히 살리로다
```
- `<교독문> 제목` 아래에 `[인도]`, `[회중]`, `[다함께]`를 적어주면 **인도 1절 + 회중 1절**이 한 장의 슬라이드에 보기 좋게 자동으로 짝지어집니다.
- 회중 파트는 성도님들이 읽기 편하도록 자동으로 더 굵은 글씨로 강조됩니다.

---

### 5. 인용구 / 명언 슬라이드 만들기
설교 중 인용할 책 구절이나 묵상 글귀를 슬라이드로 만들 수 있습니다.
```text
1. <인용> C.S. 루이스 / 우리가 하나님을 사랑하기 전에 하나님이 먼저 우리를 사랑하셨습니다.
2. <인용> 항상 기뻐하라 쉬지 말고 기도하라 범사에 감사하라
```
- 슬래시(`/`)를 넣으면 **앞쪽은 슬라이드 제목**, **뒤쪽은 본문 내용**으로 분리되어 들어갑니다.
- 본문 안에서도 `'단어' 굵게` 같은 강조 서식을 그대로 사용할 수 있습니다.

---

### 6. 🕊️ 예배 전체 템플릿 통합 기능 (고급)
매주 예배 순서 PPT(표지, 기도, 찬양, 광고, 축도 등)를 만드실 때, 성경 구절과 찬양 PPT를 하나로 합쳐주는 기능입니다.

1. **[예배 통합]** 탭으로 이동합니다.
2. **`예배 전체 템플릿에 통합하여 생성`** 체크박스를 체크합니다.
3. 예배 종류를 선택합니다:
   - `주일 예배`: 교회 주일 대예배 템플릿 기준
   - `수요 예배`: 수요 기도회/예배 템플릿 기준
   - `사용자 정의`: 직접 제작한 교회만의 PPTX 템플릿 파일 선택 가능
4. 순서 슬롯 목록이 나타납니다:
   - `{{성경봉독}}`: [구절 입력] 탭에 작성한 성경 구절이 자동으로 들어갑니다.
   - 찬양 슬롯들: [파일 선택] 버튼을 눌러 교회의 찬양 PPT 파일을 지정하거나, 파일을 마우스로 끌어다 놓습니다(Drag & Drop).
5. [PPT로 변환] 또는 [다른 이름으로 저장]을 누르면, **모든 순서가 완벽하게 결합된 하나의 최종 예배 PPT**가 완성됩니다!

---

### 7. 글꼴 및 크기 내 맘대로 바꾸기
**[서식 설정]** 탭에서 한글/영어의 제목과 본문 글꼴, 글자 크기(pt), 글자 색상을 원하는 대로 자유롭게 조정할 수 있습니다. 변경된 서식은 오른쪽 미리보기 화면에서 실시간으로 확인하실 수 있습니다.

## ❓ 자주 묻는 질문 및 문제 해결 (FAQ)

### Q1. "최초설치.bat을 눌렀는데 'python은(는) 내부 또는 외부 명령이 아닙니다'라고 떠요."
> **원인**: 파이썬을 설치할 때 환경변수 등록 옵션을 체크하지 않으셨기 때문입니다.  
> **해결 방법**:  
> 1. 다운로드했던 파이썬 설치 파일(`python-3.x.x-amd64.exe`)을 다시 실행합니다.  
> 2. `Modify` 또는 `Uninstall` 후 다시 설치를 진행하면서, 첫 화면 맨 아래의 **`Add python.exe to PATH`** 체크박스를 꼭 체크하고 설치해 주세요.

### Q2. "'npm은(는) 내부 또는 외부 명령이 아닙니다'라고 나와요."
> **원인**: Node.js가 설치되지 않았거나, 설치 직후 열려있던 터미널 창에서 명령을 실행했기 때문입니다.  
> **해결 방법**:  
> 1. [Node.js](https://nodejs.org/ko)가 정상적으로 설치되었는지 확인해 주세요.  
> 2. 설치가 끝났다면 **열려 있던 모든 창을 닫고 다시** `최초설치.bat`을 실행해 주세요.

### Q3. "PPT를 열었는데 글꼴이 밋밋하거나 기본 폰트로 나와요."
> **원인**: 템플릿에 지정된 기본 글꼴('나눔스퀘어 네오')이 사용자 컴퓨터에 설치되어 있지 않아서 윈도우 기본 폰트로 대체된 것입니다.  
> **해결 방법**:  
> - [나눔스퀘어 네오 글꼴](https://hangeul.naver.com/font/nanum)을 무료로 다운받아 설치하시거나,  
> - 프로그램의 **[서식 설정]** 탭에서 폰트 이름을 `맑은 고딕` 등 컴퓨터에 있는 글꼴 이름으로 변경해 보세요.

### Q4. "성경 구절을 찾을 수 없다는 오류가 발생해요."
> **원인**: 성경 책 이름의 약어 표기나 띄어쓰기가 맞지 않을 때 발생합니다.  
> **해결 방법**:  
> - 반드시 `창 1:1`, `마 5:3-10`, `롬 8:28` 처럼 표준 한 글자/두 글자 성경 약어와 띄어쓰기를 지켜주세요.  
>   *(창, 출, 레, 민, 신, 수, 삿, 룻, 삼상, 삼하, 왕상, 왕하, 대상, 대하, 스, 느, 에, 욥, 시, 잠, 전, 아, 사, 렘, 애, 겔, 단, 호, 욜, 암, 옵, 욘, 미, 나, 합, 습, 학, 슥, 말 / 마, 막, 눅, 요, 행, 롬, 고전, 고후, 갈, 엡, 빌, 골, 살전, 살후, 딤전, 딤후, 딛, 몬, 히, 약, 벧전, 벧후, 요일, 요이, 요삼, 유, 계)*

## 📦 독립 실행 파일(.exe)로 빌드하기 (선택 사항)

만약 매번 파이썬이나 노드 환경 없이 일반적인 설치 프로그램(`.exe`) 형태로 만들고 싶다면, 아래 명령어로 독립 패키지를 빌드할 수 있습니다:

```bash
cd electron_app_py
npm run build
```
빌드가 완료되면 `electron_app_py/dist/win-unpacked/` 폴더 내에 바로 실행 가능한 `성경 구절 PPT 변환기.exe` 파일이 생성됩니다.
